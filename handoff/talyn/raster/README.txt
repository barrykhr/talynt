TALYN — logo artwork (raster)
=============================

png/      Transparent PNG. Use these by default.
jpg/      JPEG, matted onto the background the artwork was drawn for.
          Use only where alpha is not supported.
favicon/  Square icon sizes, 16 → 512 px.

Naming
------
talyn-*          keeps the LABS descriptor
talyn-solo-*     wordmark only, no descriptor

-light   place on a LIGHT background (the mark's frame is dark)
-dark    place on a DARK background  (the mark's frame is light)
-mono    one colour, rendered in ink  #0b0b0d
-white   one colour, rendered in paper #f5f2ea  (for dark grounds)

Trailing number is the pixel width (lockups) or the square size (marks).

Sizes
-----
Lockups   1200 px and 3000 px wide
Marks      512 px and 2048 px square
JPEG      3000 px wide / 2048 px square
Favicon   16, 32, 48, 64, 128, 256, 512 px

Colours
-------
Ink     #0b0b0d
Paper   #f5f2ea
Signal  #ff4d1c

Minimum sizes: primary 120px wide, tagline 180px, stacked 72px,
submark 24px, favicon 16px. Clear space: a quarter of the mark's height.

Vector originals (SVG) are in handoff/talyn/logo/ — prefer those for print
and anywhere the size is not fixed.
